# Evaluation harness (work in progress)

Scripts that run scenarios in the lab VM and emit a results table generated
by code (not hand-typed). See `../docs/ROADMAP.md` §3 and
`../docs/RUN_ON_VM.md`.

Planned outputs per scenario: detected? / which view caught it /
time-to-detect / false-positives-per-hour on a scripted benign workload /
CPU overhead % (sensor on vs off) / syscall-dispatch mode.

This directory is intentionally a stub in the current release.
